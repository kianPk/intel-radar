# Intel Radar

**Threat intelligence console** — IoCs (IP / domain / hash / URL), severity filters, asset matches.

Live demo: **https://kianpk.github.io/intel-radar/**

## Stack

Vue 3 · Vite · Express

## Run

```bash
cd server && npm i && node index.js
cd client && npm i && npm run dev
cd client && npm run build
```
